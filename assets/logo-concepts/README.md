# Knot logo concepts

Four transparent-background logo explorations generated for Dock-size review.

- `knot-logo-option-2-task-layers.png`: layered task cards with check-shaped negative space
- `knot-logo-option-3-progress-check.png`: open progress arc with integrated check
- `knot-logo-option-4-folded-path.png`: folded pathway ending in a check

These are concept PNGs, not the currently configured application icon.
